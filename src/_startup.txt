' 0 线程僵尸进程。On Error Resume Next 也挡不住 —— 访问冲突不是
' 可捕获的 VBA 错误。
'
' 工具栏由安装器在 CorelDRAW 完全启动后写进工作区
' （DRAWUIConfig.xml），装一次就长期存在，不需要钩子。
'
' 要临时开钩子：把本文件第一行换掉，或用 build_gms.vbs --hook=<file>。
' 但任何 UI 操作都不要放进钩子。
