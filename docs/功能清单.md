## 2. 功能明细

### 2.1 拼版 — `M_Impose.Impose`

| 项 | 内容 |
|---|---|
| 前置 | 选中 ≥1 个对象 |
| 参数 | 一次输入 4 个数：`列数 行数 列间距(mm) 行间距(mm)`，默认 `3 2 5 5` |
| 输入容错 | 分隔符支持空格、`x`/`X`、`*`、`,`、中文逗号 `，`、Tab；缺省项用默认值；间距为负按 0 处理 |
| 行为 | 以选中对象为种子，按矩阵 `StepAndRepeat` 复制铺开；**原对象留在矩阵左上角**；完成后选中整个矩阵 |
| 返回 | 矩阵内对象总数 = 原对象数 × 列 × 行 |
| 边界 | 列=行=1 → 直接退出（不产生任何变化）；宽度或高度为 0 → 退出 |

### 2.2 裁切线 — `M_CropMark.CropMark`

| 项 | 内容 |
|---|---|
| 前置 | 选中 ≥1 个对象 |
| 参数 | ① 角线长度(mm)，默认 `3`；② 角线与裁切框的间距/出血(mm)，默认 `1` |
| 行为 | 取选中对象**整体包围盒**，在四角各画 2 条线段（共 8 条）组成 L 形角线；线宽 0.25mm；颜色用**套版色**（`RegistrationColor`，取不到则退化为 CMYK 100/100/100/100）；8 条线最后**群组** |
| 返回 | 画出的线段数（正常为 8） |
| 边界 | 无选中 → 提示；包围盒无效 → 退出；画不出 → 提示 |

### 2.3 书脊计算 — `M_Spine.SpineCalc`

| 项 | 内容 |
|---|---|
| 前置 | 无（不依赖选中对象） |
| 参数 | 模式 `1` / `2`；模式 1 再问「纸张克重 g/m²」「总页数」；模式 2 再问「书脊厚度 mm」「总页数」 |
| 公式 | 厚度(mm) = `0.135 × 克重/100 × 页数/2`；反算 克重 = `厚度 / (页数/2) × 100 / 0.135` |
| 行为 | 顺序 InputBox 问答，最后 MsgBox 出结果（原版 `UserForm1` 的等价流程） |
| 边界 | 任一步留空 → 退出，不弹结果 |

> 例：克重 80、页数 100 → 厚度 5.4mm。原版窗体的 `Label9 = 0.135 * dqovt/100 * (TextBox2/2)`
> 与本式一致；`Label18 = TextBox4/(TextBox3/2)*100/0.135` 即反算式。

### 2.4 中心对齐 — `M_Align.CenterAlign`

| 项 | 内容 |
|---|---|
| 前置 | 选中 ≥1 个对象 |
| 参数 | 无 |
| 行为 | 以**最底层对象**（z 序最小）的中心为基准，把所有选中对象移动到该中心。**基准对象自身不动** |
| 返回 | 被移动的对象数 |
| 边界 | 只选中 1 个 → 基准即自身，移动 0 个 → 提示「没有可对齐的对象」 |

> 语义由行为侦察确定：原按钮不是「对齐到选区中心」，而是「向底层对象收敛」。

### 2.5 按间距分布 — `M_Distribute.DistributeBySpacing`

| 项 | 内容 |
|---|---|
| 前置 | 选中 ≥2 个对象 |
| 参数 | 模式 `1` / `2`；模式 1 再问「间距 mm」，默认 `3` |
| 行为 | 按 `LeftX` 从左到右排序后：<br>**模式 1 固定间距**：最左不动，其余依次移到「前一个右边缘 + 间距」<br>**模式 2 平均分布**：最左、最右不动，中间对象等间距铺开 |
| 返回 | 被重新摆放的对象数 |
| 边界 | 间距为负 → 提示并退出；对象数不足 → 提示 |

### 2.6 删除线段 — `M_DelSegment.DelSegment`

| 项 | 内容 |
|---|---|
| 前置 | 选中 ≥1 个对象 |
| 参数 | 无 |
| 行为 | 分两种场景：<br>① 曲线对象上**选中 ≥2 个节点** → 删除这些节点及其间的线段（`NodeRange.Delete`）<br>② 选中**直线段对象**（`IsLineSegment`）→ 删除整个对象 |
| 返回 | 处理成功的对象数 |
| 边界 | 都不满足 → 提示「没有找到可删除的线段」 |

## 4. 已知限制

1. **窗体降级**：X4 的 `.bas` 无法导入 UserForm，`书脊计算` 用 InputBox 顺序问答代替原窗体（流程等价，外观不同）。
2. **裁切线不做智能避让**：原 `AutoCutLines` 里有基于 Python 的旅行商式排线，本实现只做标准四角角线。
3. **拼版不做多页**：只做当前页内的矩阵复制，不跨页。
4. **单位随文档**：所有 mm 输入按当前文档单位换算（默认英寸文档下 5mm ≈ 0.1969）。
5. **本机 5 个 0 线程僵尸 `CorelDRW.exe`**（PID 3020/3540/8316/9012/15148）：杀不掉，需重启系统清理；不影响本插件的构建、安装与运行。
