# 优化问题总结 · TypesetToolkit v1.0.0

> 汇总 v1.0.0 交付后仍存在的**功能、工程、环境、兼容性**四类优化点，附优先级与建议。
> 证据来源：`PROGRESS.md`（验证证据）、`PLAN.md`（每个坑含报错原文）、`CHANGELOG.md`、`logs\build.log`。
> 结论先行：**6 个功能全部可用并通过三层验证**；下列问题均**不影响当前使用**，属"下一版可做"的清单。

## 1. 功能层（还原度与深度）

| 编号 | 问题 | 现状 / 证据 | 建议方案 | 优先级 |
|---|---|---|---|---|
| **F1** | 书脊计算交互降级 | 原版是 `UserForm1` 窗体；X4 的 `.bas` 无法导入窗体，现改为 **InputBox 顺序问答**（`CHANGELOG.md` 已知限制 1） | 用代码**动态创建 UserForm**（`VBA.UserForms.Add` + 运行时 `Controls.Add`），还原单页表单体验 | 中 |
| **F2** | 裁切线无智能排线 | 原 `AutoCutLines` 含基于 Python 的旅行商式排线；本实现只画标准四角 L 形角线（`docs\功能清单.md` 已知限制 2） | 增加"多对象分别裁切"与"按对象分组生成角线"；智能避让可后置 | 中 |
| **F3** | 拼版不支持跨页 / 自动行列 | 只做**当前页内**的矩阵复制，行列需手工输入（已知限制 3） | 增加"按页面尺寸 + 对象尺寸自动算行列"；跨页拼版需处理页对象复制，成本较高 | 中 |
| **F4** | 中心对齐只有一种语义 | 固定为"所有对象收敛到**最底层对象**中心"，无方向/基准可选（`docs\功能清单.md` §2.4） | 增加选项：水平对齐 / 垂直对齐 / 对齐到选区中心 / 对齐到页面中心 | 低 |
| **F5** | 按间距分布只有水平方向 | 仅按 `LeftX` 从左到右排列（§2.5） | 增加垂直方向、双向（行列同时等距） | 低 |
| **F6** | 删除线段不做端点重连 | 删节点/删对象后不自动连接剩余端点（§2.6） | 增加"删除后自动连接断口"（`Segment` 重建） | 低 |

> 补充：6 个功能均为**一次性执行**，未做显式事务回滚；操作在中途失败（如输入非法）时**已按设计提前退出**，
> 但大对象集上的部分写入行为**尚未做压力实测**，建议下一版补一条"中途失败不留半成品"的用例。

## 2. 工程 / 构建层（可复现性）

| 编号 | 问题 | 现状 / 证据 | 建议方案 | 优先级 |
|---|---|---|---|---|
| **E1** | 构建强依赖本机 X4 | `build_gms.vbs` 通过 VBE 自动化编译，需本机安装 CorelDRAW X4（`README.md` §六） | 无 X4 环境**无法编译**；如需 CI，只能把 GMS 作为制品缓存，CI 侧只做文档/脚本 lint | 中 |
| **E2** | GMS 二进制不入库 | `.gitignore` 明确排除 `dist/TypesetToolkit.gms`，产物只以 base64 内嵌进安装器 | ✅ **已处理**：v1.0.0 已用 **GitHub Release** 归档 `TypesetToolkit.gms`（138770 B，SHA-256 `83D1776D…E4D701A`），见 [releases/tag/v1.0.0](https://github.com/Ri1035/cdrx4-typeset/releases/tag/v1.0.0)；后续版本沿用此方式 | 已解决 |
| **E3** | 脚本纯 ASCII 约束 | PowerShell 5 / WSH 按 ANSI 解析脚本，中文一律 base64 内嵌（`installer_template.txt` 等） | 评估 `chcp 65001` + UTF-8 with BOM 的可行性；或把文案统一外置为 UTF-8 数据文件 | 低 |
| **E4** | 无自动化回归 | 三层验证（BUILD / smoke / LAUNCH）需人工触发，且依赖真实 X4 进程与 GUI | 把三层串成一个 `verify_all.ps1`，一条命令出结论；崩溃判定已由 `tools\verify_toolbar.ps1` 自动化 | 中 |
| **E5** | GMS 内不含版本号 | 运行时无法自证版本，只能靠 CHANGELOG 与文件字节数 | 编译期把版本号写入一个 `M_Util.AppVersion` 常量，`M_Install.DiagToolbar` 一并回显 | 低 |
| **E6** | 工具栏依赖工作区文件 | 不装启动钩子（启动期建 CommandBars 必崩），工具栏由安装器写 `DRAWUIConfig.xml`；**用户切换 / 新建工作区后工具栏会消失** | 在 README 明示"换工作区需重装"；或提供"仅重建工具栏"的轻量入口 | 低 |

## 3. 环境遗留（本机）

| 编号 | 问题 | 证据 | 处理 |
|---|---|---|---|
| **H1** | 5 个 0 线程僵尸 `CorelDRW.exe` | `Get-CimInstance Win32_Process` → PID 15148/9012/3020/8316/3540，`ThreadCount=0`，`Stop-Process -Force` 无效 | **重启系统**清理（用户手动执行；助手禁止重启）。不影响插件构建/安装/运行 |
| **H2** | X4 退出自动回写 GMS | 构建失败时半成品会被写回 `User Draw\GMS`（`PLAN.md` §3.2） | 已用 `Fail()` 循环重删（20×500ms）缓解；未根治，属 X4 行为 |

## 4. 兼容性（已知取舍，暂不改）

| 编号 | 约束 | 说明 |
|---|---|---|
| **C1** | 仅 CorelDRAW X4 | X5+ 的 `.gms` 架构不同，不通用 |
| **C2** | 单位随文档 | 所有 mm 输入按**当前文档单位**换算（英寸文档下 5mm ≈ 0.1969） |
| **C3** | 需 X4 勾选 VBA | 未装 VBA 组件的 X4 无法运行 GMS 宏 |
